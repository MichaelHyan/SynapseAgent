# 天气技能

获取当前天气状况和预报。

## 命令

### 当前天气

请使用powershell。

```bash
# 单行摘要
curl "wttr.in/Beijing?format=3"

# 详细当前状况
curl "wttr.in/Beijing?0"

# 特定城市
curl "wttr.in/Beijing?format=3"
```

### 预报

```bash
# 3 天预报
curl "wttr.in/Beijing?format=3"

# 本周预报
curl "wttr.in/Beijing?format=v2"

# 特定日期（0=今天，1=明天，2=后天）
curl "wttr.in/Beijing?1"
```

### 格式选项

```bash
# 单行
curl "wttr.in/Beijing?format=%l:+%c+%t+%w"

# JSON 输出
curl "wttr.in/Beijing?format=j1"

# PNG 图像
curl "wttr.in/Beijing.png"
```

### 格式代码

- `%c` — 天气状况表情符号
- `%t` — 温度
- `%f` — "体感温度"
- `%w` — 风速
- `%h` — 湿度
- `%p` — 降水量
- `%l` — 地点

## 快速响应

**"会下雨吗？"**

```bash
curl -s "wttr.in/Beijing?format=%l:+%c+%p"
```

**"周末预报"**

```bash
curl "wttr.in/Beijing?format=v2"
```

## 注意事项

- 不需要 API 密钥（使用 wttr.in）
- 受速率限制；不要发送过多请求
- 适用于大多数全球城市
- 支持机场代码：`curl wttr.in/ORD`
