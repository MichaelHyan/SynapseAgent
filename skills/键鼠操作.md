坐标规范：左上角为(0,0)

指令列表
```bash
#获取整张屏幕截图
screen
#获取屏幕截图和可操作元素位置，调用后返回每个可操作元素的框的序号和中心坐标
screen_cord
#只处理某一区域，从屏幕坐标(x1,y1)->(x2,y2)
screen_cord [x1,y1,x2,y2]
#在某坐标点击，调用后会返回一次屏幕截图
click [x] [y] [left/right] [点击次数]
#输入文字，仅限英文，调用后会返回一次屏幕截图
typewrite [英文文字]
```

示范：

```bash
<tool_call>screen</tool_call>
<tool_call>screen_cord</tool_call>
<tool_call>screen_cord [1,2,3,4]</tool_call>
<tool_call>click 1 1 left 1</tool_call>
<tool_call>typewrite test</tool_call>
```

使用前提醒用户**是否真的要允许接管**，并告知**这是一种效率极低且不稳定，也不合理的操作方式**。

## 输入方式选择与输入法处理

### 一、核心原则

`typewrite` 是**模拟键盘按键**，它输入的结果 = 按键序列 × **当前输入法状态**。

命令类方式（`powershell start`、构造 URL）**不经过键盘，不受输入法影响**，可靠性最高。

**优先级：命令行/URL 直达 > 剪贴板粘贴 > typewrite（英文态） > typewrite（中文态，禁止）**

### 二、什么时候用 PowerShell（不要用 typewrite）

**只要能靠"启动"或"链接"一步到位的，一律不用 typewrite。**

### 三、什么时候必须用 typewrite（且必须先切英文）

仅当目标**是一个没有地址栏、没有命令入口的输入框**时才用，例如：
- 网页内的搜索框、表单、评论框
- 应用内的搜索/设置输入框

**使用 typewrite 前必须确认输入法为英文**，否则英文单词会被拼音转换。

### 四、输入法切换方法（typewrite 前执行）
```bash
# 切换到英文输入法（Win 默认：Win+Space，部分输入法为 Shift 或 Ctrl+Space）
powershell $w=New-Object -ComObject WScript.Shell; $w.SendKeys('+')      # Shift 切换中英（搜狗/QQ输入法常用）
powershell $w=New-Object -ComObject WScript.Shell; $w.SendKeys('^{SPACE}') # Ctrl+Space 切换输入法
```

推荐流程（每次 typewrite 前）：

```bash
# 1. 点击目标输入框聚焦
click [x] [y] left 1
# 2. 确认/切换为英文输入状态
powershell $w=New-Object -ComObject WScript.Shell; $w.SendKeys('+')
# 3. 输入英文内容（空格直接用真实空格）
typewrite bad apple
# 4. 截图核对，内容错误则全选删除重来
```

### 五、内容输入规范
| 项目 | 规范 |
| --- | --- |
| 空格 | 直接用真实空格 ` `，**禁止用 `&#32;` 等 HTML 实体** |
| 中文字符 | 不要用 typewrite；改用文件/剪贴板/URL 编码 |
| 特殊符号 | 尽量避开；必须用时先小段测试 |
| 清零旧内容 | `click` 后发送 `^a` `{DEL}`，或三击全选后直接输入覆盖 |
| 每组输入 | 分段输入 + 每段截图确认，不要一次长串 |

### 六、输入前后校验（必做）

1. **输入前**：截图确认光标已在目标框内（有光标/边框高亮）。
2. **输入后**：截图核对内容是否与预期完全一致。
3. **不一致**：不要在此基础上追加，先清空再重输。

### 七、常见故障速查
| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 只输入了第一个字符 | 浏览器联想/自动补全截断 | 改用 powershell 打开或 URL 直达 |
| 英文变成中文 | 输入法处于中文模式 | 切英文后重输 |
| 输入到别处 | 焦点不在目标框 | 重新点击聚焦后再输 |
| 出现 `&#32;` 字样 | 误用 HTML 实体 | 改用真实空格 |
| 点击后无反应 | 坐标失效/被弹层遮挡 | 重新 `screen_cord` 取坐标 |
